# pixmoving_hmi_driver


## 车辆状态机
- 车辆驾驶模式: 
  - 1:遥控模式, 
  - 2:自驾模式 - 待命状态(遥控器放权，自驾等待执行)
  - 3:自驾模式 - 执行状态; 6:自驾模式 - 遥控接管; 7:自驾模式 - 刹车接管;
  - 8:自驾模式 - 完成; 9:自驾模式 - 接管取消; 10:自驾模式 - 新任务取消;
  - 4:远程驾驶状态; 5:紧急停止状态; -1:未知;

自驾执行 -> 自驾完成 -> 自驾待命 -> 遥控驾驶
        -> 自驾完成 -> 自驾待命 -> 自驾执行
        -> 自驾接管 -> 接管取消
        -> 自驾接管 -> 自驾执行
        -> 新任务取消
        -> 接管取消
遥控驾驶 -> 自驾接管
